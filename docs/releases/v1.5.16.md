# 码熊 v1.5.16

v1.5.16 为表详情增加多标签浏览能力，方便同时学习和对照多张数据表。

## 本次更新

### 表详情标签页

- 可同时打开多张数据表，在标签页之间快速切换。
- 从搜索结果、表关系或 AI 助手跳转表时，已打开的表会直接复用原标签。
- 每个标签独立保留编辑草稿，切换表时不会丢失未保存修改。
- 有未保存修改的标签会显示提示标记。
- 关闭标签时可选择保存并关闭、放弃修改或继续编辑。
- 支持关闭当前标签、关闭其他标签和关闭右侧标签。
- 支持 `Ctrl/Cmd + W` 关闭当前标签、`Ctrl/Cmd + Tab` 切换标签。
- 刷新工作台后会恢复已打开的标签和当前激活的表。

### 搜索体验

- 搜索结果不会自动打开第一行，只有主动点击表格后才会记录“最近打开”。
- 每个搜索上下文最多保留 10 张最近打开的数据表用于排序和标记。

### 兼容与安全

- 保留原有工作台布局、表列表和字段字典编辑方式。
- 标签页只管理当前工作区的浏览状态，不会新增或修改 PDM 数据结构。
- PDM 写回仍保留原文件备份，并继续执行外部修改检查。

## 版本与平台

- Windows 10/11 x64：`CodeBear-v1.5.16-win-x64.zip`
- macOS 13 及以上 Apple Silicon：`CodeBear-v1.5.16-mac-arm64.dmg`

当前 Mac 版只支持 M 系列芯片，暂不支持 Intel Mac。

正式发布后请从 [GitHub Releases](https://github.com/Eco1i/CodeBear/releases/tag/v1.5.16) 下载。Windows 和 macOS 是两个独立安装包，请按自己的系统选择。
