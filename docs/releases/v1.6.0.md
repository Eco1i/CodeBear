# 码熊 v1.6.0

v1.6.0 带来明亮 / 暗夜主题、中文 / English 界面切换，并重新设计密集表格与列表的滚轮体验。

## 本次更新

### 明亮 / 暗夜主题

- 可在偏好设置中切换明亮和暗夜主题，选择会在刷新及重新启动后保留。
- 主题覆盖工作台、项目目录、数据表、字段字典、弹窗、关系图、DDL 编辑器、备份迁移和 AI 助手。
- 统一暗夜主题下数据表勾选、悬停和当前行背景，移除选中行边缘白线。
- 优化 DDL 数据库标识、字典表格、备份进度、关系筛选和缩放控件等细节的对比度与交互状态。

### 中文 / English 界面

- 可在偏好设置中切换中文和 English 界面，选择会在刷新及重新启动后保留。
- 覆盖主要操作、搜索、编辑、备份迁移、字典中心、表关系、DDL 导出、AI 助手和更新提示。
- 表名、字段名、项目名称、PDM 文件名等用户数据保持原样，不会被翻译。

### 整行滚轮滚动

- 鼠标滚轮每格移动一整行，以平滑动画停在完整行边界。
- 浏览器缩放后仍按逻辑行连续滚动，不会因亚像素位置而卡住或只响应一次。
- 适用于数据表、字段、字典、DDL 和关系列表等原生滚动区域。
- 保留触控板精细滚动、键盘操作、滚动条拖动、减少动态效果模式和关系图画布缩放。

### 其他体验改进

- 项目目录宽度拖动改为按动画帧同步更新，目录和字段工作区更跟手。
- 数据表标签较多时，鼠标停在标签栏即可直接使用滚轮横向浏览。
- 备份迁移、导出 SQL 和字典中心窗口默认居中，并支持拖动标题栏移动。
- 补全新增表关系窗口的关系类型和手工维护说明，关系方向筛选的选中状态更明确。
- 重复启动桌面版时会打开正在运行的实例；服务仍在准备时会显示更明确的状态说明。

## 下载

请从 [GitHub Releases](https://github.com/Eco1i/CodeBear/releases/tag/v1.6.0) 下载与系统对应的安装包和 SHA-256 校验文件：

- Windows 10/11 x64：`CodeBear-v1.6.0-win-x64.zip`
- Windows SHA-256：`CodeBear-v1.6.0-win-x64.zip.sha256`
- macOS 13 及以上 Apple Silicon：`CodeBear-v1.6.0-mac-arm64.dmg`
- macOS SHA-256：`CodeBear-v1.6.0-mac-arm64.dmg.sha256`

Windows 和 macOS 安装包不能混用。macOS 版仅支持 Apple Silicon（M 系列芯片），暂不支持 Intel Mac。

## 升级说明

- Windows：将新版本完整解压到新目录，再通过“备份迁移”导入旧版数据；不要直接覆盖仍在运行的旧目录。
- macOS：将新版 `CodeBear.app` 拖入“应用程序”并替换旧版；应用数据仍保存在 `~/Library/Application Support/CodeBear`。
- 当前 macOS 版未经过 Apple 公证。首次启动时可在 Finder 中右键选择“打开”，或在“系统设置 > 隐私与安全性”中允许打开。
