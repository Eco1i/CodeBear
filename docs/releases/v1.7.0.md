# 码熊 v1.7.0

v1.7.0 修复数据表和字段字典的鼠标滚轮末尾滚动问题，并优化偏好设置弹层的连接视觉。

## 本次更新

### 偏好设置弹层

- 左上角偏好设置的三角箭头与面板连续连接，主题和语言入口保持统一的气泡视觉。

### 文件导出

- 导出备份包和 SQL 时，Chromium 系浏览器会打开系统保存对话框，可直接选择文件位置。
- Safari、Firefox 和其他不支持原生保存对话框的浏览器继续使用浏览器默认下载流程。

### 滚轮滚动修复

- 修复 macOS 触摸板连续滚动表格时被自定义行滚动动画拖慢的问题，连续像素滚动现在交由浏览器原生处理。
- 修复视口高度不是表格行高整数倍时，滚动到末尾最后一行只显示部分内容的问题。
- 滚动到列表底部时允许到达浏览器原生最大滚动位置，确保最后一行完整显示。
- 修复从末尾向上滚动时的行位置衔接，避免跳过上一行完整边界。
