# 码熊 v1.5.15

v1.5.15 新增搜索记忆，并修复 Windows 绿色版退出后后台进程残留的问题。

## 下载

- Windows 10/11 x64：`CodeBear-v1.5.15-win-x64.zip`
- macOS 13 及以上 Apple Silicon：`CodeBear-v1.5.15-mac-arm64.dmg`

当前 Mac 版只支持 M 系列芯片，暂不支持 Intel Mac。

## 本次更新

### 搜索体验

- 记住最近打开的数据表，在后续搜索中优先展示相关结果。
- 按当前项目和搜索模式保存搜索记忆，不受具体关键词变化影响。
- 搜索结果按精确匹配、最近打开且匹配、前缀匹配、普通包含匹配和描述/注释匹配排序。
- 搜索记忆默认开启，可在搜索偏好中关闭或清除。
- 搜索记忆最多保留 100 条、保存 90 天，并最多提升 3 张相关数据表。

### Windows 绿色版

- 修复退出后后台服务进程、端口和单实例状态未及时释放的问题。
- 关闭程序时会先尝试正常停止服务；遇到正在处理的请求时，也会在有限等待后完成退出，避免进程长期残留。

## 安装与升级

Windows 用户请将 ZIP 完整解压到新目录后运行 `CodeBear.exe`。升级时建议通过“备份迁移”导入旧版数据，不要将新旧版本文件混合在同一目录。

macOS 用户打开 DMG 后，将 `CodeBear.app` 拖入“应用程序”。当前 Mac 版只支持 Apple Silicon，且未经过 Apple 公证；首次启动可能需要在 Finder 中右键选择“打开”。

Windows 数据保存在程序同级的 `data` 目录，macOS 数据保存在 `~/Library/Application Support/CodeBear`。升级或替换程序不会自动删除原有数据。
