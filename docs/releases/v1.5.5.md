# 码熊 v1.5.5

v1.5.5 修复浮动模式关闭 AI 助手后，悬浮入口短暂被遮挡或显示异常的问题。

## 下载

- Windows 10/11 x64：`CodeBear-v1.5.5-win-x64.zip`
- macOS 13 及以上 Apple Silicon：`CodeBear-v1.5.5-mac-arm64.dmg`

当前 Mac 版只支持 M 系列芯片，暂不支持 Intel Mac。

## 本次更新

- 修复关闭助手后悬浮入口短暂被面板遮挡的问题。
- 悬浮入口会在助手面板完全退出后正常显示，打开助手时不会遮挡对话内容。

## 安装与升级

Windows 用户完整解压 ZIP 后运行 `CodeBear.exe`。升级测试时请解压到新目录，避免与旧版程序文件混合；需要沿用数据时，可通过“备份迁移”导入旧版数据。

本补丁包含 v1.5.0 至 v1.5.4 的字段与数据表结构维护、AI 助手入口拖动、窄工作区操作列适配和删除窗口样式更新。
