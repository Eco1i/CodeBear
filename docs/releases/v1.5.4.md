# 码熊 v1.5.4

v1.5.4 修复关闭 AI 助手后悬浮入口短暂呈现为被白色内容层遮住的问题。

## 下载

- Windows 10/11 x64：`CodeBear-v1.5.4-win-x64.zip`
- macOS 13 及以上 Apple Silicon：`CodeBear-v1.5.4-mac-arm64.dmg`

当前 Mac 版只支持 M 系列芯片，暂不支持 Intel Mac。

## 本次更新

- 移除助手关闭后悬浮入口自身的二次淡入和位移动画。
- 入口仍会等待助手面板完成退出，再直接以完整不透明、最终位置恢复。
- 修复关闭助手后入口短暂显示异常的问题。

## 安装与升级

Windows 用户完整解压 ZIP 后运行 `CodeBear.exe`。升级测试时请解压到新目录，避免与旧版程序文件混合；需要沿用数据时，可通过“备份迁移”导入旧版数据。

本补丁包含 v1.5.0 至 v1.5.3 的字段与数据表结构维护、AI 助手入口拖动、窄工作区操作列适配和删除窗口样式更新。
