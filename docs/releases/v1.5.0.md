# 码熊 v1.5.0

v1.5.0 补全了 PDM 结构维护能力：现在可以在“编辑字典”中新增和删除字段，也可以在数据表列表中单独或批量删除表。

## 下载

- Windows 10/11 x64：`CodeBear-v1.5.0-win-x64.zip`
- macOS 13 及以上 Apple Silicon：`CodeBear-v1.5.0-mac-arm64.dmg`

当前 Mac 版只支持 M 系列芯片，暂不支持 Intel Mac。

## 本次更新

- “编辑字典”支持新增字段、删除普通字段，以及原有字段和表信息修改。
- 新增字段会校验英文名、数据类型和重复代码；新字段以轻量底色标识。
- 主键字段、存在表关系或字典绑定的字段会受到删除保护。
- 数据表列表新增逐行删除按钮，勾选多张表后可批量删除。
- 删除确认会展示受影响的字段、关系、字典绑定和 PDM 数量。
- 表删除会同步清理 PDM 中的原生外键关系与图形符号。
- 所有结构变更都会先自动备份 PDM；文件版本冲突或写回失败时停止操作并保留原数据。

## 使用说明

### 新增或删除字段

选择数据表后点击“编辑字典”。使用“新增字段”在末尾添加字段，或使用字段行末尾的删除按钮移除普通字段；确认内容后统一点击“保存修改”。保存前点击“取消”可以放弃本次编辑。

### 删除数据表

使用数据表行末尾的删除按钮删除单表。需要批量处理时，先勾选多张表，再点击顶部的“批量删除”。核对影响范围后确认即可。

删除前生成的 PDM 原文件副本会保留在工作区备份目录。请注意，已明确提示并同步移除的手工表关系与字典绑定不包含在 PDM 文件内。

## 安装与升级

Windows 用户完整解压 ZIP 后运行 `CodeBear.exe`。macOS 用户打开 DMG 后将 `CodeBear.app` 拖入“应用程序”。升级前建议使用“备份迁移”导出当前数据。
