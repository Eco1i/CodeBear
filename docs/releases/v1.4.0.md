# 码熊 v1.4.0

v1.4.0 新增 Mac 版。Windows 和 Mac 版是两个独立安装包，请按自己的系统下载。

## 下载

- Windows 10/11 x64：`CodeBear-v1.4.0-win-x64.zip`
- macOS 13 及以上 Apple Silicon：`CodeBear-v1.4.0-mac-arm64.dmg`

当前 Mac 版只支持 M 系列芯片，暂不支持 Intel Mac。

## 本次更新

- 新增 macOS 桌面版，从菜单栏打开工作台、数据目录或检查更新。
- 更新功能会根据当前系统提供对应的 Windows 或 Mac 安装包。
- Windows 版继续提供绿色 ZIP，原有功能和使用方式不变。

## 安装与升级

### Windows

完整解压 ZIP 后，双击 `CodeBear.exe`。升级时建议解压到新目录，再通过“备份迁移”导入旧版数据。

### macOS

打开 DMG，把 `CodeBear.app` 拖入“应用程序”。升级时先退出旧版，再用新版替换即可，原有数据不会被删除。

当前版本未经过 Apple 公证。首次启动时，请在 Finder 中右键 `CodeBear.app`，选择“打开”；如果系统仍然拦截，请前往“系统设置 > 隐私与安全性”选择仍要打开。

## 数据与隐私

- Windows 数据保存在程序同级的 `data` 目录。
- macOS 数据保存在 `~/Library/Application Support/CodeBear`。
- AI 助手需要你自己的 DeepSeek API Key。密钥由当前系统账户加密保存，在 Mac 上使用登录钥匙串。
- 码熊只处理导入后的 PDM 副本，不会修改原始 PDM 文件。
