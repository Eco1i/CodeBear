# 码熊 v1.4.0

本版本新增 macOS Apple Silicon 桌面版。Windows 与 macOS 共用业务源码和版本号，但始终提供两个独立安装包。

## 下载

- Windows 10/11 x64：`CodeBear-v1.4.0-win-x64.zip`
- macOS 13+ Apple Silicon：`CodeBear-v1.4.0-mac-arm64.dmg`
- 每个安装包均提供同名 `.sha256` 文件用于完整性校验。

请按操作系统下载对应文件。当前 macOS 包仅支持 M 系列芯片，暂不支持 Intel Mac。

## macOS 支持

- 新增独立 `CodeBear.app` 和 DMG，使用菜单栏图标打开工作台、数据目录、更新页面或退出应用。
- 数据、设置和 PDM 工作副本保存在 `~/Library/Application Support/CodeBear`。
- DeepSeek API Key 保存在当前用户的 macOS 登录钥匙串中。
- 支持 Finder 数据目录入口、原生错误提示、POSIX 单实例锁和平台中性的工作区路径处理。
- 更新检查会按当前平台和 CPU 架构选择正确的 DMG，不会下载 Windows ZIP。

当前 DMG 采用 ad-hoc 签名且未经过 Apple 公证。首次启动请在 Finder 中右键 `CodeBear.app` 并选择“打开”；若仍被拦截，请前往“系统设置 > 隐私与安全性”选择仍要打开。

## Windows 与升级

- Windows 继续提供 x64 绿色 ZIP，数据仍保存在程序同级 `data` 目录。
- Windows 升级建议解压到新目录，再通过“备份迁移”读取旧版 `data`。
- macOS 升级时退出旧版，将新版拖入“应用程序”并替换；Application Support 中的数据会继续保留。

## 构建与验证

- Windows ZIP：完成前端构建、PyInstaller 打包、解压启动、健康接口、前端页面和数据目录创建验收。
- macOS DMG：在 GitHub 原生 Apple Silicon runner 上完成 PyInstaller 打包、ad-hoc 签名、应用启动、镜像校验、挂载及签名复验。
- Windows 与 macOS 的后端、前端和浏览器端到端测试均通过。
- macOS arm64 安装包已在真实 Apple Silicon Mac 上完成试用验证。

## 隐私说明

- 正式包由 GitHub Actions 从 `v1.4.0` 标签对应的干净源码构建。
- 发布前检查受控源码，打包后再次检查安装包内容；`data`、数据库、真实 PDM、`.cbbak` 备份、设置、API Key 和本地原型文件不会进入发布物。
- 应用仍只监听 `127.0.0.1`，不会向局域网或公网开放。
- AI 功能保持可选，使用者需自行提供 DeepSeek API Key。
