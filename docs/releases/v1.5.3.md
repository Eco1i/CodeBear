# 码熊 v1.5.3

v1.5.3 修正 v1.5.2 中数据表删除窗口、AI 助手关闭尾帧和操作列分隔线的界面问题。

## 下载

- Windows 10/11 x64：`CodeBear-v1.5.3-win-x64.zip`
- macOS 13 及以上 Apple Silicon：`CodeBear-v1.5.3-mac-arm64.dmg`

当前 Mac 版只支持 M 系列芯片，暂不支持 Intel Mac。

## 本次更新

- 数据表删除确认窗口改为与工作台一致的紧凑样式，清楚展示待删除对象、字段、表关系、字典绑定和 PDM 影响范围。
- 自动备份保护单独展示，危险操作与取消操作保持清晰区分。
- AI 助手入口等待面板真实完成退出后再出现，不再与退出中的面板发生短暂遮挡。
- 操作列分隔线与普通列统一为同样的 1px 浅色线，并移除额外阴影。
- 删除窗口补充准确的辅助技术名称，图标不会混入标题朗读。

## 安装与升级

Windows 用户完整解压 ZIP 后运行 `CodeBear.exe`。升级测试时请解压到新目录，避免与旧版程序文件混合；需要沿用数据时，可通过“备份迁移”导入旧版数据。

本补丁包含 v1.5.0 的字段与数据表结构维护能力、v1.5.1 的 AI 助手入口拖动与位置记忆能力，以及 v1.5.2 的窄工作区操作列适配。
